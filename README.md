## Instalación (XAMPP – phpMyAdmin)
1. Importar `APE2_instalacion.sql` desde la pestaña **Importar** (juego de caracteres utf-8).
2. Seleccionar `gestion_investigacion` y ejecutar, una por una, las consultas de `APE2_consultas_y_pruebas.sql` en la pestaña **SQL**.

## Archivos
| Archivo | Contenido |
|---|---|
| `APE2_instalacion.sql` | Crea toda la base: modelo, datos, funciones, procedimientos y triggers |
| `APE2_consultas_y_pruebas.sql` | Consultas de los apartados 2 y 3 y pruebas P01 a P12 |
| `01_modelo_fisico.sql` … `05_pruebas.sql` | Scripts por separado |
| `INCIDENCIAS.md` | Registro de las 9 incidencias |
